🤲 Adhkar Companion Bot

Adhkar Companion هو بوت Telegram مفتوح المصدر يساعد المستخدم على المحافظة على الأذكار اليومية، من خلال توفير أذكار الصباح والمساء ومجموعة متنوعة من الأدعية والأذكار الإسلامية.

الميزة الأساسية في المشروع هي الإرسال التلقائي للأذكار حسب التوقيت المحلي للمستخدم، بحيث تصل أذكار الصباح والمساء دون الحاجة إلى طلبها يدويًا.

---

✨ المميزات

- 🌅 أذكار الصباح.
- 🌙 أذكار المساء.
- 🤲 مجموعة من الأدعية والأذكار الإسلامية.
- 🕌 أذكار الصلاة.
- 😴 أذكار النوم.
- 📚 تصفح جميع الأذكار المتوفرة.
- ⏰ إرسال تلقائي للأذكار.
- 🌍 دعم المناطق الزمنية المختلفة.
- ⚙️ إمكانية تشغيل وإيقاف التذكيرات.
- 🕕 الإرسال الافتراضي:
  - أذكار الصباح: 06:00 صباحًا
  - أذكار المساء: 06:00 مساءً
- 💾 حفظ إعدادات المستخدم.
- 🔓 مشروع مفتوح المصدر.
- 🚂 جاهز للنشر على Railway.

---

🕐 نظام التوقيت المحلي

لا يعتمد البوت على توقيت خادم Railway فقط.

يتم حفظ المنطقة الزمنية الخاصة بالمستخدم، وبناءً عليها يحدد البوت موعد إرسال الأذكار.

مثال:

المستخدم 1
Asia/Aden
06:00 صباحًا → أذكار الصباح
18:00 مساءً → أذكار المساء

المستخدم 2
Africa/Cairo
06:00 صباحًا → أذكار الصباح
18:00 مساءً → أذكار المساء

وبذلك يحصل كل مستخدم على الأذكار وفق توقيته المحلي.

- إنشاء Telegram Bot من @BotFather.

---

🔐 إعداد المتغيرات

أنشئ ملفًا باسم:

.env

وأضف:

BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
ADMIN_ID=YOUR_TELEGRAM_USER_ID

لا ترفع ملف ".env" إلى GitHub.

استخدم ".env.example" لمشاركة أسماء المتغيرات المطلوبة فقط:

BOT_TOKEN=
ADMIN_ID=

---

💻 التشغيل محليًا

استنسخ المشروع:

git clone https://github.com/YOUR_USERNAME/adhkar-companion-bot.git

انتقل إلى مجلد المشروع:

cd adhkar-companion-bot

ثبت المتطلبات:

pip install -r requirements.txt

أنشئ ملف ".env" وأضف بيانات البوت.

ثم شغّل:

python main.py

---

🚂 النشر على Railway

يمكن نشر المشروع بسهولة على Railway.

1. ارفع المشروع إلى GitHub

أنشئ مستودعًا جديدًا ثم ارفع ملفات المشروع.

2. أنشئ مشروعًا في Railway

اختر:

Deploy from GitHub Repo

ثم اختر مستودع:

adhkar-companion-bot

3. أضف المتغيرات

داخل Railway → Variables أضف:

BOT_TOKEN
ADMIN_ID

4. التشغيل

بعد اكتمال عملية النشر سيبدأ البوت بالعمل تلقائيًا.
